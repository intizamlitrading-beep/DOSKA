# Intizamli Trading — Onlayn doska

Sızıw, trading qurallari (trend sızıǵı, Fibonachchi, kanal, traektoriya, svechalar) hám logo menen onlayn doska.

## GitHub Pages arqalı saytqa shıǵarıw

1. github.com ǵa kiriń (akkaunt joq bolsa, Sign up).
2. Joqarı oń tárepte **+ → New repository**.
   - Repository name: `intizamli-doska`
   - **Public** tańlań
   - Create repository
3. Ashılǵan betten **uploading an existing file** siltemesin basıń.
4. Usı papkadaǵı **hámme fayldı** (index.html, sw.js, manifest.json, barlıq .png) sürip taslań. Zip emes, ishindegi fayllar.
5. Tómende **Commit changes** basıń.
6. **Settings → Pages** ǵa kiriń.
   - Source: **Deploy from a branch**
   - Branch: **main** hám **/ (root)** → **Save**
7. 1–2 minuttan keyin sayt shıǵadı:
   `https://SIZDIŃ-ATIŃIZ.github.io/intizamli-doska/`

## Programma retinde ornatıw
Saytı Chrome yamasa Edge-de ashıń. Adres qatarındaǵı ornatıw ikonkası yamasa doskadaǵı "···" → "Programma retinde ornatıw" basıń.

## Jańalıq kirgiziw
Repository ishinde `index.html` di ashıp, qalam ✎ túymesi menen almastırıń (yamasa Add file → Upload files menen jańa faylın jükleń). Commit etkennen 1–2 minut keyin sayt jańalanadı.
